# V100 SXM2 연결 구성

확인일: 2026년 11월 21일 KST

## 장착 구성

| 항목 | 구성 |
| --- | --- |
| GPU | Tesla V100-SXM2-16GB × 2 |
| 장착 보드 | AOM-SXMV |
| 호스트 물리 연결 | PCIe 3 연결 단자 두 개로 메인보드에 연결 |
| GPU 간 연결 | NV2, 활성 NVLink 2개 |
| PCIe 스위치 | PLX PEX 8764 |
| 메인보드 | ASUS ProArt B650-CREATOR |

## OS에서 확인한 PCIe 경로

```text
CPU Root Port 0000:00:01.1
└── PEX 8764 0000:01:00.0
    ├── 0000:02:04.0 → bus 03, 하위 장치 미열거
    ├── 0000:02:08.0 → V100 0000:04:00.0
    └── 0000:02:0c.0 → V100 0000:05:00.0
```

| 구간 또는 장치 | 확인 시점 링크 | 보고 최대 링크 |
| --- | --- | --- |
| CPU Root Port 0000:00:01.1 | 8.0 GT/s ×16 | 16.0 GT/s ×16 |
| PEX 업스트림 0000:01:00.0 | 8.0 GT/s ×16 | 8.0 GT/s ×16 |
| V100 경로 0000:02:08.0 | 8.0 GT/s ×16 | 8.0 GT/s ×16 |
| V100 0000:04:00.0 | 8.0 GT/s ×16 | 8.0 GT/s ×16 |
| V100 경로 0000:02:0c.0 | 8.0 GT/s ×16 | 8.0 GT/s ×16 |
| V100 0000:05:00.0 | 8.0 GT/s ×16 | 8.0 GT/s ×16 |

8.0 GT/s는 PCIe 3.0이다. 열거된 PCIe 경로에서는 두 GPU가 하나의 PCIe 3.0 ×16 호스트 업링크를 공유한다. 링크 값은 확인 시점의 sysfs 보고값이다.

## NVIDIA 정보

| 항목 | 확인값 |
| --- | --- |
| 커널 모듈 버전 | 580.196.07 |
| GPU 드라이버 바인딩 | 두 GPU 모두 nvidia |
| GPU VBIOS | 두 GPU 모두 88.00.4f.00.09 |
| NVIDIA-SMI 및 드라이버 버전 | 580.196.07 |
| GPU당 VRAM | 16,384 MiB |
| GPU당 전력 제한 | 300 W |
| Persistence Mode | 두 GPU 모두 On |
| Compute Mode | 두 GPU 모두 Default |
| Volatile Uncorrectable ECC | 두 GPU 모두 0 |
| NVLink 토폴로지 | GPU 0 ↔ GPU 1: NV2 |
| 활성 NVLink | 두 GPU 모두 Link 3 및 Link 5 |
| NVLink 보고 링크 속도 | 활성 링크당 25.781 GB/s, 대역폭 실측값 아님 |
| CPU 및 NUMA affinity | 두 GPU 모두 CPU 0–11, NUMA 0 |

nvidia-smi 헤더의 CUDA Version은 13.0이다. 이는 드라이버가 지원하는 CUDA 버전이며, 설치된 Toolkit 또는 strata의 CUDA 런타임 버전을 뜻하지 않는다.

조회 시점에 strata 프로세스가 두 GPU의 VRAM을 사용 중이었다.
